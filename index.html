Finding seizures in two-second slices of EEG

This project trains EEGNet, a compact convolutional neural network built for EEG, to label short EEG windows as seizure or non-seizure. This page shows the data, the test results on unseen patients, and a comparison between the original training run and an undersampled one.

Illustrative synthetic signal, not patient data. The red section mimics the rhythmic, high-amplitude look of a seizure.

Research only. This is not a clinically validated diagnostic system and must not inform medical decisions.

How EEGNet works

What happens to one window, in order. Exact operations and intermediate tensor shapes depend on the implementation and configuration used here, so none are listed.

  1. Input, shape (19, 512)19 EEG channels with 512 time samples each.
  2. Temporal convolutionSlides small filters along time to learn useful signal patterns.
  3. Depthwise spatial convolutionLearns combinations across channels, meaning which electrode locations work together.
  4. Batch normalization and activationNormalization keeps values stable during training. The activation adds nonlinearity so the network can learn complex patterns.
  5. Pooling and dropoutPooling shrinks the representation. Dropout randomly switches off units during training to limit overfitting.
  6. Separable convolutionLearns more temporal features with fewer parameters than a standard convolution.
  7. Classification layerOutputs a score for each class: seizure and non-seizure.

The filters are learned from the training data. Nobody programmed in what a seizure looks like.

Training

Two separate choices. The best checkpoint is picked by validation PR-AUC. The threshold is picked afterwards by maximizing validation F1. The test set is used for neither.

The undersampling experiment

The original training set has 16,575 non-seizure windows against 792 seizure windows. To test whether a more balanced set helps, the second run keeps all 792 seizure windows and picks five non-seizure windows for each (3,960). Only the training distribution changes. Validation and test sets are untouched.

PR-AUC is on a 0 to 1 scale, as recorded.

The selected operating point improved: higher F1 and recall, slightly higher precision, and almost no change in PR-AUC. That suggests a better threshold-level trade-off, but it does not prove undersampling helps on other datasets or patients.

Findings and limits

What happened

  • The undersampled model detected more seizure windows in the test set.
  • Recall improved and precision rose slightly in this experiment.
  • PR-AUC barely moved, so the overall precision-recall ranking changed very little.

What to be careful about

  • Only three patients are in the test set, so results may not generalize.
  • Overlapping windows are correlated and are not independent observations.
  • A high threshold is not clinical certainty. Predicted probabilities may be poorly calibrated.
  • These results are experimental and establish neither clinical safety nor diagnostic accuracy.
